## 🌟 Overview

A high-performance, dark cinematic developer portfolio designed for **Mohammad Ejaz Mehendi** (Full Stack Developer & Computer Vision Enthusiast). Featuring a interactive 3D particle sphere globe background, electric crimson accents, glassmorphic cards, custom inertia cursor, and responsive editorial layout.

---

## ✨ Key Features

- **🌐 Interactive 3D Particle Globe**: Pure Canvas 2D/3D Fibonacci sphere algorithm with mouse parallax interaction and atmospheric red core glow.
- **🎨 Dark Cinematic Design**: Custom CSS design system with HSL variables, dark glass panels (`#080808`), and glowing electric crimson (`#ff0033`) typography.
- **💼 Selected Projects Showcase**: 16:9 high-resolution futuristic dashboard cover cards for **Qstream AI**, **Unified Student Placement System**, and **Bank Account Management System**.
- **🎯 Interactive Skills Matrix**: Categorized tech stack tags with hover glow reactive feedback.
- **📜 Professional Timeline**: Vertical experience timeline highlighting internship achievements at **Syntexchub**.
- **🎓 Academic & Achievement Cards**: Real-time stats badges (**9.36 CGPA**, **200+ LeetCode**, **10+ Projects Built**).
- **📱 Fully Responsive**: Smooth mobile drawer navigation and fluid responsive grid layouts for all screen dimensions.
- **📄 Downloadable Resume**: Integrated download link for `Resume3.pdf`.

---

## 🛠️ Tech Stack & Tools

- **Frontend**: React 18, HTML5, Vanilla CSS3 (Custom Design System)
- **Animations**: Framer Motion (`useInView`, scroll reveals)
- **3D & Visuals**: HTML5 Canvas 2D API (Custom 3D Fibonacci Sphere Math)
- **Icons**: Lucide React + Inline Brand SVGs
- **Build Tool**: Vite 5

## 🚀 Quick Start & Local Setup

### Prerequisites
- Node.js (`v18.x` or higher)
- npm (`v9.x` or higher)

### Installation & Running Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ejazmehendi123-cell/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
